# 場面7 誰が使えるかを選ぶ

- 目的：みんなが使う画面を、誰が開けるようにするかを決めるため
- 本人がやる理由：公開する範囲は本人が決めること

## 選択肢（選んだ結果で説明する。おすすめを先頭に）

会社のGoogleアカウント（Google Workspace）の場合：

> このアプリを使えるのは誰にしますか？
> 1. 社内の人だけ（おすすめ）：会社のGoogleアカウントでログインした人だけが開けます
> 2. 自分だけ：まずは自分だけで試します
> 3. Googleアカウントがある人なら誰でも：社外の人も、URLを知っていれば開けます

個人のGmailの場合（「社内の人だけ」は選べない）：

> このアプリを使えるのは誰にしますか？
> 1. 自分だけ（おすすめ）：まずは自分だけで使います
> 2. Googleアカウントがある人なら誰でも：URLを知っていてGoogleにログインした人が開けます

「URLを知っている人なら誰でも（ログイン不要）」は、本人から求められたときだけ示し、誰でも中身を見られることを先に伝える。

あわせて、誰の権限で動かすかを決める。通常は「作った人（あなた）の権限で動く」をすすめる。使う人にスプレッドシートの権限を渡さなくても使えるため。

## AIの動き

- 選ばれた内容を `src/appsscript.json` の `webapp` に書く

| 選択 | access | executeAs |
| --- | --- | --- |
| 自分だけ | MYSELF | USER_DEPLOYING |
| 社内の人だけ | DOMAIN | USER_DEPLOYING |
| Googleアカウントがある人なら誰でも | ANYONE | USER_DEPLOYING |
| URLを知っている人なら誰でも | ANYONE_ANONYMOUS | USER_DEPLOYING |

- 書き換えたら `npm run push` で送る。みんなが使う画面に反映されるのは、場面8で本人が「公開する」を押したときだけ

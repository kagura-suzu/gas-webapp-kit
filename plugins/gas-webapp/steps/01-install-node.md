# 場面1 土台ソフト（Node.js）を入れる

- 目的：パソコンとGoogleをつなぐ道具を動かすため
- 本人がやる理由：パソコンへのインストールで、Windowsの確認が出る

## AIの動き

1. 先に承認をもらう：

   > 道具を動かすための土台ソフト（Node.js）がまだ入っていません。入れてもよいですか？ 無料の公式ソフトで、5分ほどかかります。

2. 「はい」の返事を得てから実行する。
   - Windows：`winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements`
   - Mac：公式サイト（https://nodejs.org/）のインストーラーを案内する。Homebrewが入っていれば `brew install node`
3. 実行中に出る確認を案内する。

## 案内の文例

> 画面に「このアプリがデバイスに変更を加えることを許可しますか？」と出たら、「はい」を押してください。押せたら「できました」と送ってください。

## 確かめ方

- 新しいシェルで `node -v` を実行し、v20以上であることを確かめる
- インストール直後は、いま開いているシェルに反映されないことがある。そのときは `doctor` を新しいシェルで実行するか、本人にアプリの再起動をお願いする（「一度このアプリを閉じて、開き直してください。続きから再開します」）

## うまくいかないとき

- wingetが無い・会社の設定でインストールできない：公式サイトのインストーラー（LTS）を案内する。それも止められている場合は場面9（管理者の許可）

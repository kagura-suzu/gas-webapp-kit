# 場面9 会社の管理者の許可が要るとき

- 目的：会社の設定で止められている操作を、管理者に許可してもらうため
- 本人がやる理由：本人では変えられない

## 見分け方

次のような表示や結果が出たとき：

- 「管理者によってブロックされています」「This app is blocked」「admin_policy_enforced」
- Apps Script API のスイッチが押せない
- Node.js のインストールが会社の設定で止められる

## 案内の文例

> 会社のGoogleの設定で、この操作が止められているようです。会社の管理者の方に許可をもらう必要があります。そのまま送れる文章を用意しました。社内のチャットやメールで管理者の方に送ってください。

## 管理者に送る文面（場面に合わせて1つ選ぶ）

clasp（パソコンからGASを操作する道具）が止められている場合：

> お疲れさまです。業務用のWebアプリを Google Apps Script で作るため、Googleの公式の開発ツール「clasp」を使いたいと考えています。
> 現在、私のアカウント（メールアドレス）でclaspの許可画面がブロックされています。Google 管理コンソールの「セキュリティ」→「アクセスとデータ管理」→「API の制御」で、clasp（Google Apps Script CLI）へのアクセスを許可していただけないでしょうか。
> 必要なのは、私が作るスクリプトとスプレッドシートの操作だけです。よろしくお願いいたします。

Apps Script を使えない設定の場合：

> お疲れさまです。業務用のWebアプリを Google Apps Script で作りたいと考えています。私のアカウント（メールアドレス）で Apps Script が使えない設定になっているようです。Google 管理コンソールで Apps Script の利用を許可していただけないでしょうか。よろしくお願いいたします。

## AIの動き

- 文面の「（メールアドレス）」は、ログイン中のアカウントに置き換えてから渡す
- 管理者の設定をAIが変えることはしない
- 許可が出たら、止まっていた場面からやり直す

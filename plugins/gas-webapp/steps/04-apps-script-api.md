# 場面4 Googleの設定でスイッチを入れる（Apps Script API）

- 目的：パソコンからGASを操作できるようにするため（最初の1回だけ）
- 本人がやる理由：アカウントの設定変更

## AIの動き

1. アプリ内ブラウザで https://script.google.com/home/usersettings を開く
2. スクリーンショットで、スイッチの場所と今の状態を確かめてから案内する

## 案内の文例

> パソコンから操作するためのスイッチを入れます。右の画面の「Google Apps Script API」の横にあるスイッチを押して「オン」にしてください。英語の画面なら「Google Apps Script API」の横のスイッチで、「On」になればOKです。できたら「できました」と送ってください。

## 確かめ方

- スクリーンショットでスイッチがオンになったことを確かめる
- 反映まで数分かかることがある。1〜2分待ってから、止まっていた作業（アプリの作成やGoogleに送る）をもう一度実行する
- それでも「has not enabled the Apps Script API」と出る場合は、さらに数分待って再実行する

## うまくいかないとき

- スイッチが押せない・灰色：会社の管理者の設定。場面9へ
